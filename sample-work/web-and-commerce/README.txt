# Waves Commerce — sample works

Each subfolder of THIS folder is a tab in the modal. Inside every tab
folder, freely mix (files ordered by the number in their name):

  PHOTOS      1.png, 2.jpg, 3.webp …
  VIDEOS      1.mp4, 2.mov, 3.webm …  (vertical/horizontal auto-detected)
  HTML FILES  1.html, 2.html …        (undeployed or local interactive site)
  LINK FILES  1.txt, 2.txt …  one URL each on the first line, optionally
              " | label" — website URLs, YouTube/Vimeo, Drive, Dropbox,
              X/Twitter, Streamable, Dailymotion, Loom, TikTok, Instagram,
              Facebook, or any direct photo/video link. Lines starting with
              # are ignored. (Drive files must be shared "Anyone with the link".)

WEBSITE SLOT BUNDLING (same number = one unified website card):
Website cards accept a preview video and/or an HTML file (ordered by slot number):
  1.mp4   → muted looping preview video in the card (supports .mp4 / .mov / .webm)
  1.html  → live interactive site opened directly when you click the preview card
            (also renders directly in the tile if no preview video is present)
  1.txt   → optional paired website URL for the bar domain label and OPEN ↗ when
            paired with a matching .mp4 or .html file (standalone URL-only website
            .txt files without a video or HTML file are ignored)

Add / rename / delete folders freely — tabs follow automatically.

This README is ignored by the gallery.
